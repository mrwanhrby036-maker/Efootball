# تحليل مشروع NEXUS ULTRA V5

## نظرة عامة
مشروع ويب شامل يسمى "NEXUS ULTRA V5" منصة أدوات رقمية مجانية، تم تطويره بتاريخ 23 نوفمبر 2026، ويتضمن أكثر من 10 أدوات مختلفة باللغة العربية ( RTL).

## الهيكل التنظيمي

```
/ (الجذر) - index.html - point of entry
  .env.example - إعدادات الخادم
  .gitignore - قواعد ignore
  .vercelignore -ignored files for deployment
  vercel.json - إعدادات النشر
  ads.txt - ملف إعلانات
  sitemap.xml - ملف السايتيماب
  Efootball/ - directory containing all tools and APIs
```

## الملفات الأساسية

### 1. index.html
- نقطة الدخول الرئيسية للموقع
--layout RTL باللغة العربية
- includes Cairo & Orbitron fonts
- 12 صفحة أدوات مدمجة
- Meta tags للبحث ومحركات التواصل الاجتماعي
- CSP headers م konfigurated

### 2. Efootball/api/tiktok.js
- API endpoint لاستخراج فيديوهات تيك توك
- validates URLs according to TikTok pattern
- supports quality options: 144p, 360p, 480p, 720p, 1080p
- rate limiting (20 requests/minute)
- timeout handling (8 seconds)
- error handling with Arabic messages
- Uses tikwm API كمصدر خارجي

### 3. Efootball/api/youtube.js
- API endpoint لتحميل فيديوهات يوتيوب
- يتطلب COBALT_API_URL كمتغير بيئي
- supports qualities: 144p, 360p, 480p, 720p, 1080p
- modes: video or audio
- rate limiting (20 requests/minute)
- timeout handling (12 seconds)
- validates video IDs (11 characters)

### 4. Efootball/server.js
- serveur HTTP المحلي
- serves static files
- كان يحتوي على serving records unrestricted تم استبدالها بقائمة allowlist
